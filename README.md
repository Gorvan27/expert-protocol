# Expert Protocol — скилл для Claude

Универсальный разбор задачи одной командой `/expert-protocol`:

1. **Диагноз** — реальная потребность и ошибки в постановке
2. **Вопросы** — 2–3 вопроса эксперта; ответы из контекста, иначе помечены как допущения
3. **Ответ** — факты отдельно от оценок, с альтернативами
4. **Предупреждение** — главная ошибка в такой ситуации

Подстраивает глубину под задачу, не подставляет выдуманные числа, останавливается и спрашивает, если без ответа решение будет ошибочным. Режим «только перепиши мой запрос» — по словам «перепиши запрос» / «подготовь промпт».

## Установка

**Claude Code:** скопируйте папку `expert-protocol/` в `~/.claude/skills/`.

**Claude (сайт / приложение):** упакуйте папку `expert-protocol/` в ZIP (`zip -r expert-protocol.zip expert-protocol`) → Customize → Skills → «+» → Upload a skill. Вызов: `/expert-protocol <ваша задача>`.

Перед установкой откройте `expert-protocol/SKILL.md` и прочитайте — скилл это просто инструкции для Claude.
